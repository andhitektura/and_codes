# Член 63

Светлите мерки на средствата за затворање изнесуваат:

1) за врата со праг:

- 625 x 1800 mm;

- 800 x 1800 mm;

- 1000 x 1800 mm;

- 1100 x 2000 mm;

2) за обична врата без праг;

- 625 x 1850 mm;

- 800 x 1850 mm;

- 1000 x 1850 mm;

- 1100 x 2000 mm;

3) за вертикални капаци;

- 625 x 800 mm;

- 625 x 1200 mm;

4) за хоризонтални – обични капаци;

- 600 x 600 mm; или

- φ 600 mm;

5) за подвижни прегради;

- 1600 x 2000 mm;

- 2000 x 2250 mm;

- 3000 x 2250 mm;

Средствата за затворање можат да имаат и други димензии, ако тоа се бара од посебни причини.
