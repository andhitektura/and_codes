# Член 129

Секое ложиште треба да има посебна димоводна цевка.

По исклучок од став 1 од овој член, ложиште може да се приклучи на заедничка димоводна цевка по одредбите од став 3 член [[ПР-09-Член 123|123]] од овој правилник.
