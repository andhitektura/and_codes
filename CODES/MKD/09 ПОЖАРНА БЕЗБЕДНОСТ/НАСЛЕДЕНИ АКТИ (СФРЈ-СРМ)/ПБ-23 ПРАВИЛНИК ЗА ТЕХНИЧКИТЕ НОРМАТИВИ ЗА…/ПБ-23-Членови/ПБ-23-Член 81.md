# Член 81

Превозот со возила со гумена пневматика создава мошне поволни услови за појавување на статичен електрицитет.

При превозот со возила на течни експлозивни материјали можат да се појават искри. Заради спречување појавување на статичен електрицитет возилата мораат да бидат заземјени според член [[ПБ-23-Член 85|85]] на овој правилник.
