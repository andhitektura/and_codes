# Член 37

Спроводливите подови што се користат во системот за одведување на статичниот електрицитет, мораат да имаат преодна отпорност помала од 10⁸ ома. Преодната отпорност на подовите мора да се контролира во временските растојанија што ги одредува соодветната стручна служба на организацијата на здружениот труд.

Материјалите за изработка на спроводливи подови и нивната преодна отпорност се дадени во следната таблица:

| Материјал | Измерен отпор во оми |
|---|---|
| Плочички | 10⁷ — 10⁹ |
| Штици за бродски под | 10⁶ — 10¹⁰ |
| Линолеум | 10⁶ — 10¹⁰ |
| Спроводна гума | 10² |
| Печени плочички | 10⁷ — 10¹⁰ |
| Вештачки камен — неспроводен | 10¹¹ |
| Обичен бетон со дебелина 3 cm | 10⁵ |
| Специјален бетон со дебелина 5 cm | 10² |
| Спроводен пенлив под | 10² |
| Терацо | 10⁵ — 10⁷ |
| Спроводлив терацо | 10³ |
| Асфалт | 10¹⁰ |
