# Член 16-а

| Единица | | Точност |

| | Висина | 0.3 m |
| | Интервал на регистрација | 1s |
| INS | Агол околу Х оска | 0.015° |
| | Агол околу У оска | 0.015° |
| | Агол околу Z оска | 0.035° |
| | Интервал на регистрација | 0.016 s |
